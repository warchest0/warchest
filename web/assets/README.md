# Asset provenance

- `seal.svg`, `seal-icon.svg`, `seal-mono-bone.svg`, `wordmark-ink.svg`, `wordmark-bone.svg`, `og.png`: the Warchest seal and wordmark, generated by `brand/logos/seal/build.mjs` (all lettering outlined).
- `InterVariable.woff2`: Inter by Rasmus Andersson, self-hosted from https://github.com/rsms/inter. `JetBrainsMono.woff2`: self-hosted from Google Fonts (latin subset). Both under the SIL Open Font License (licence files next to them). No third-party font requests at runtime.
- `earth.jpg`: NASA Blue Marble Earth imagery, via the three.js example asset https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/textures/planets/earth_atmos_2048.jpg, retrieved 2026-09-29. NASA image policy: https://www.nasa.gov/nasa-brand-center/images-and-media/. Used as the hero globe surface; no NASA endorsement implied.
- `world.geojson`: Natural Earth world polygons (public domain), retrieved 2026-09-29 from https://raw.githubusercontent.com/holtzy/D3-graph-gallery/master/DATA/world.geojson. Terms: https://www.naturalearthdata.com/about/terms-of-use/. Used for the dotted treasury globe.
